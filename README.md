# Sarah's Tiny Movement Test

A tiny, single-screen browser prototype for checking the feel of side-view movement. It uses plain HTML, CSS, and JavaScript. There are no dependencies, downloads, or separate art files.

## Try it locally

Open `index.html` in a modern web browser.

## Controls

- Left/Right arrows or A/D: move
- Space, Up arrow, or W: jump
- E: open or close the house door when nearby
- R: return Sarah to the starting point

Sarah can jump onto the small step and activate the house door when she is nearby. Health, Save Blocks, painting, companions, and story are not implemented yet.

## Put it on GitHub

Upload `index.html` and `README.md` to the root of your repository. To share a playable web version, enable GitHub Pages for the repository and publish from the branch containing these files.
